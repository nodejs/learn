# Node version managers

Node version managers facilitate multiple versions of node installed at the same time on the same machine, as well as managing updates. This is useful when different projects use different versions of node. Some automatically detect the version the project uses, whilst others require manual switching.

Popular node version managers are:

- [`asdf`](https://github.com/asdf-vm/asdf)
- [`fnm`](https://github.com/Schniz/fnm)
- [`mise`](https://github.com/jdx/mise)
- [`n`](https://github.com/tj/n)
- [`nave`](https://github.com/isaacs/nave)
- [`nvm`](https://github.com/nvm-sh/nvm) - an OpenJS project
- [`nvm for windows`](https://github.com/nvm-windows/nvm) - not affiliated with nvm
- [`nvs`](https://github.com/jasongin/nvs)
- [`volta`](https://github.com/volta-cli/volta)
